# GitHub Spec Kit

This repository is a template for starting standardized web projects.
It provides:
- Branch model and recommended GitHub settings
- CI/CD workflows (example Node/React)
- Issue & PR templates
- Docs and onboarding checklists
- Starter `src-template/` for a web project

Usage:
1. Use this repo as a template (GitHub "Use this template") to create new projects.
2. Replace placeholders in `docs/` and `README_TEMPLATE.md`.
